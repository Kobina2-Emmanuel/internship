Common difference (d): the fixed amount added to get from one term to the next. Here d = 3.
Arithmetic Progression (AP): a sequence in which each term differs from the one before it by the same constant, the common difference d. The first term is called a.

Is it an AP? If yes, what is d?

Challenge (take-home)

In an AP, T3 = 11 and T7 = 23. Find the first term a, the common difference d, and the expression for Tn.

Show hints

Write each term with the formula: T3 = a + 2d = 11 and T7 = a + 6d = 23. Subtract one equation from the other to find d, then find a.

Show answer (after you have tried!)

d = 3, a = 5, so Tn = 5 + (n − 1)3 = 3n + 2.
